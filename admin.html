Cómo leer estas métricas

La analítica web incluye únicamente visitas con estadísticas opcionales permitidas. Un navegador puede pertenecer a varias personas y una persona puede usar varios navegadores. Las sesiones caducan tras 30 minutos sin eventos. Las vistas, secciones y clics proceden de eventos del navegador y pueden incluir tráfico automatizado; no equivalen a personas verificadas.

Registros y correos confirmados se consultan por separado en la base de cuentas, independientemente del consentimiento estadístico. No se enlazan con el identificador de navegación. No recogemos emails, contraseñas, contenido de formularios, URLs completas, IP en la tabla analítica ni archivos de mods. Los eventos se conservan hasta 90 días. Las comparaciones solo aparecen cuando existe un periodo anterior completo; 90 días no tiene comparación.

Los datos comienzan desde la activación. No se reconstruye tráfico histórico. Este panel mide la web, no el uso de mods dentro de la aplicación de escritorio.
